# Support

AgentLocalCI is a volunteer open-source project with no service-level agreement.

Use GitHub Issues for reproducible bugs, documentation problems, and focused feature proposals. Include AgentLocalCI version and exact commit, host OS/architecture, PowerShell, Git, Docker Desktop/Engine and Docker architecture, exact sanitized command, expected result, actual result, and a minimal public fixture.

For macOS reports, state whether the machine is Apple Silicon or Intel and whether the issue is controller/installer behavior or a project dependency that ships only x86 binaries.

Use GitHub Discussions when enabled for usage questions and design conversations. Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities or possible sensitive-data exposure.

Do not post private repository contents, personal paths, access tokens, `.env` files, CI logs containing customer data, or production configuration.
