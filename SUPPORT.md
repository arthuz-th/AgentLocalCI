# Support

AgentLocalCI is a volunteer open-source project with no service-level agreement.

Use GitHub Issues for reproducible bugs, documentation problems, and focused feature proposals. Include versions, the exact command, sanitized configuration, expected result, actual result, and a minimal public fixture.

Use GitHub Discussions when enabled for usage questions and design conversations.

Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities or possible sensitive-data exposure.

Do not post private repository contents, personal paths, access tokens, `.env` files, CI logs containing customer data, or production configuration.
