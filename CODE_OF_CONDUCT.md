# Community code of conduct

AgentLocalCI contributors and maintainers commit to a respectful, technically rigorous, and harassment-free community.

## Expected behavior

- Discuss code, evidence, risk, and trade-offs rather than attacking people.
- Be precise about what was tested and what remains uncertain.
- Welcome good-faith questions from people with different experience levels.
- Protect private data and move vulnerability reports to the private security channel.
- Accept maintainer decisions on security boundaries even when they make a feature less convenient.

## Unacceptable behavior

Harassment, threats, discrimination, sexualized conduct, doxxing, deliberate disclosure of private data or unpatched vulnerabilities, sustained disruption, impersonation, and knowingly falsified test or security evidence are not acceptable.

## Enforcement

Report conduct concerns privately to the maintainers through a GitHub private security advisory when confidentiality is needed, or through a repository issue when it is safe to discuss publicly. Maintainers may edit or remove content, lock discussions, reject contributions, or temporarily or permanently restrict participation.

Enforcement decisions should be proportionate, documented privately, and avoid unnecessary disclosure of reporters or affected people.
